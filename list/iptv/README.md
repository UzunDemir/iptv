# ru_iptv — парсер рабочих потоков российских каналов

Собирает российские каналы из публичных M3U-источников, проверяет каждый поток
на живость (HLS: master → вариант → реальный сегмент; MPEG-TS: фактические байты;
DASH: валидный MPD) и формирует один плейлист только из работающих ссылок.

## Быстрый старт

```
python -m ru_iptv
```

Результат: `playlist.m3u` (только рабочие каналы) и `report.json` (полный отчёт
о проверке: коды ответов, задержки, разрешения, причины отказов).

На Windows можно запускать через `run.bat`.

## Как это работает

1. Скачивает источники из `sources.txt` (по умолчанию iptv-org: `countries/ru.m3u`
   и `languages/rus.m3u`).
2. Парсит `#EXTINF` (имя, `tvg-id`, логотип, группа, `#EXTVLCOPT` User-Agent).
3. Проверяет потоки параллельно (aiohttp), не доверяя одному лишь HTTP 200:
   - **HLS**: master-плейлист → выбирает лучший вариант (разрешение/битрейт) →
     скачивает первый сегмент (для fMP4 дополнительно init-сегмент `EXT-X-MAP`);
   - **MPEG-TS / raw**: читает первые килобайты, отсекает HTML/JSON-заглушки;
   - **DASH**: валидирует структуру MPD;
   - проверка TLS-сертификата отключена — самоподписанные сертификаты, как в плеерах.
4. Дедупликация: один канал (`tvg-id`, иначе имя) — один лучший поток
   (выше разрешение, ниже задержка).
5. Пишет плейлист и отчёт.

## Параметры

- `--sources FILE` — файл со списком источников (по умолчанию `sources.txt`)
- `--out FILE` — итоговый плейлист (по умолчанию `playlist.m3u`)
- `--report FILE` — отчёт (по умолчанию `report.json`)
- `--workers N` — параллельных проверок (64)
- `--timeout S` — таймаут на поток, сек (12)
- `--retries N` — повторы при сетевых ошибках (1)
- `--min-height PX` — минимальная высота кадра, 0 = без фильтра
  (у raw-потоков высота неизвестна и считается 0)
- `--hls-only` — только HLS-потоки
- `--all-variants` — не схлопывать дубликаты каналов
- `--limit N` — ограничить число кандидатов (для тестов)
- `--no-report` — не писать отчёт
- `--probe URL [URL ...]` — проверить отдельные ссылки и выйти

Примеры:

```
python -m ru_iptv --limit 20 --workers 16          # быстрый тест на 20 потоках
python -m ru_iptv --min-height 720 --out hd.m3u    # только HD
python -m ru_iptv --probe https://example.com/live/index.m3u8
```

## Свои источники

Добавьте URL или путь к локальному `.m3u` в `sources.txt`, по одной строке
на источник.

## Зависимости

```
pip install -r requirements.txt
```

Нужны `aiohttp` и `requests` (в Anaconda обычно уже установлены).

## Замечания

- Источники — публичные открытые списки (iptv-org и др.). Ответственность
  за использование конкретных потоков и их правовой статус лежит на пользователе.
- Часть потоков привязана к региону/провайдеру: при запуске из другой сети они
  могут не проходить проверку, даже если работают «изнутри».
- Если канал не прошёл проверку, но есть в источнике — попробуйте запустить
  проверку позже: у потоков бывают плановые перерывы.
